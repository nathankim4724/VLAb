# smolvla-keys

`features.yaml` and `tasks.yaml` from https://huggingface.co/jadechoghari/smolvla-keys at revision
`b05eb487e7b42ec148a4e4022db81c22f1fcd579` (last modified 2025-07-07). Upstream VLAb downloads them at
import time; this fork reads these copies instead, so training needs no network and the mapping is
versioned with the code. Set `VLAB_ASSETS_DIR` to use a different directory.

Local changes are made in separate commits on top of the original files (see `git log -- assets/`).
